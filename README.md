# AcademicManager

**AcademicManager** — автоматизована інформаційна система обліку наукових публікацій викладачів, розроблена в межах курсового проєкту.

## 📋 Про проєкт

Програма призначена для зберігання та впорядкування інформації про викладачів і їхні наукові публікації.

Система дозволяє вести облік публікацій, знаходити необхідні записи та редагувати інформацію за допомогою графічного інтерфейсу.

## ⚙️ Основні можливості

- Додавання, перегляд, редагування та видалення викладачів.
- Додавання, перегляд, редагування та видалення наукових публікацій.
- Пошук і фільтрація записів.
- Відображення кількості викладачів і публікацій.
- Збереження даних у локальній базі даних SQLite.

## 🛠️ Використані технології

- **Мова програмування:** C#
- **Платформа:** .NET
- **Графічний інтерфейс:** Windows Forms
- **База даних:** SQLite
- **Середовище розробки:** Visual Studio

## 🚀 Запуск проєкту

1. Завантажте репозиторій на комп'ютер.
2. Відкрийте файл `AcademicManager.slnx` у Visual Studio.
3. Дочекайтеся відновлення необхідних залежностей.
4. Запустіть проєкт за допомогою клавіші `F5`.

Для запуску необхідні Windows, Visual Studio та відповідна версія .NET SDK.

## 📁 Структура проєкту

- `AcademicManager.slnx` — файл рішення Visual Studio.
- `AcademicManager.csproj` — файл конфігурації проєкту.
- `Program.cs` — точка входу в програму.
- `MainForm.cs` — основна логіка та графічний інтерфейс програми.
- `MainForm.resx` — ресурси форми.
- `README.md` — опис проєкту.
